# 🎮 Platformer Adventure Game

A fun multi-level 2D platformer game built using HTML, CSS, and JavaScript.

## 🚀 Game Description

Platformer Adventure is a browser-based platform game where the player jumps across platforms, collects coins, avoids enemies, and reaches the portal to complete levels.

The game includes physics, gravity, enemy movement, moving platforms, and a full level progression system.

---

## ✨ Features

- 🕹️ Player movement system
- ⬆️ Jump + gravity physics
- 🟫 Static platforms
- 🔄 Moving platforms
- 🪙 Coin collection system
- 👾 Enemy AI movement
- 🚪 Portal win system
- 🎯 Score system
- 📈 Level progression (Level 1 → Level 5)
- 💀 Game over system
- 🎨 Responsive UI
- ⚡ Smooth gameplay

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

---

## 🎮 Controls

| Key | Action |
|---|---|
| ⬅️ Left Arrow | Move Left |
| ➡️ Right Arrow | Move Right |
